📅 时区设置:
   • GitHub Actions 使用 UTC 时间
   • AEST (澳大利亚东部标准时间) = UTC + 10
   • AEST 18:00 = UTC 08:00
   • Workflow cron: '0 8 * * *'

💰 费用:
   • GitHub Actions: 免费额度 (每月2000分钟)
   • Google News RSS: 完全免费
   • Gmail SMTP: 免费

🔒 安全:
   • 敏感信息存放在 GitHub Secrets (不是代码里)
   • .env 文件用于本地测试
   • .env.template 提交到 GitHub (不含真实密码)

📦 依赖:
   • requests (HTTP请求)
   • beautifulsoup4 (解析RSS)
   • smtplib (Python内置)
